## UX contract

**Open and return.** Trigger: selected exercise History → options → RM curve. Steps: open a native stack page with the selected exercise, choose one gym (Unspecified is a separate cohort), inspect, then Back. Success: History's exercise, metric, focused week and scroll context survive; workout logging is untouched. Edge: muscle History offers no curve action; deleted/unavailable exercise gets a StatePanel and Back. Navigation is a proposal, wired only in the final exposure task.

**Choose scope.** Trigger: exercise picker or gym/range/effort button. Steps: use existing Sheet/ListRow radio choices; commit a single choice immediately and dismiss; show the applied value. Proposed default: latest 12 weeks ending today, all known RIR, most recently trained gym cohort for that exercise, including Unspecified (stable ID breaks ties). Range choices: 4, 12, 24 weeks or the configured History look-back; shorter options clamp to History bounds. Never widen that look-back. Effort choices: all known RIR plus each canonical numerical RIR available in the scoped history, including high RIR. Reference uses the same gym/effort scope, six qualifying prior sessions strictly before the displayed range, within the independently anchored History look-back; changing range or effort coherently recomputes it. Fewer priors means no reference, with observations retained. Exercise changes select its most recent gym and clear selection; other changes retain a still-visible set ID or clear it. No automatic replacement selection.

**Inspect and compare a set.** Trigger: tap a point or activate View sets. Steps: choose the nearest point/group in a minimum 44pt target; if several candidates collide, open the chronological set list (newest first; session/set order then binary ID tie-break), choose one, and return to its readout. Success: selection has a caret/text cue; readout shows date, actual Reps, RIR, equivalent reps, chart Load, logged Weight and unchanged 1RM. Previous/Next follows the same visible-set ordering; boundaries disable the unavailable direction. Every set is reachable through the list, including fully coincident marks; counts never replace individual observations. Filters clear stale details. Edge: no selection prompts a tap or View sets. Selection is independent of baseline availability.

**Read the chart and its limits.** Trigger: resolved scoped history. Steps: inspect scatter at x=m+n and chart load y=L/F, the fixed historical reference and dated legend. Success: older-to-newer recency uses viz1–4, outlined marks, recency relative to the selected range and exact dates in the accessible list; line uses ink, never record/gain or statistical significance. A single point still renders. Missing/unknown effort stays excluded and its count/reason is visible; it is never RIR0. No completed sets, no known effort, or an empty filtered result has a distinct message and filter action. Loading has a StatePanel; read failure removes stale chart/details and offers Retry. With fewer than six priors, say Reference unavailable / N of 6 prior sessions while keeping scatter/readout. Zero load remains a valid axis/figure, not a missing value. No confidence band, break badge or weekly fitted curve.

**Review weekly progress.** Trigger: design review's synthetic replay frames, separate from product controls. Steps: inspect completed prefixes of the same frozen plateau history; compare weeks 2/6/10/14/18/22 and stable/smooth controls. Success: same-load RIR1→2→3 moves equivalent reps while the fixed M100 curve stays unchanged; higher load at RIR1 preserves analytical equivalence. Numeric expectations come from the frozen oracle, with no future observations. Smooth control is a methodology example, not a forecast. Insufficient baseline uses the same evaluation data with only five qualifying priors. These review controls are not a new app weekly-replay feature.

**Access values without the plot.** Trigger: VoiceOver or small/tall text viewport. Steps: focus named filters, chart summary and View sets; browse every dated set as a labelled button; select and read details. Success: no drag-only selection or colour-only information; charts are supplemental to text/list access. All controls reach 44pt, filters wrap vertically without horizontal scrolling; body/readout wraps while numbers retain existing formats. Picker dismissal returns focus to its trigger; selection announces updated details. A later implementation review verifies actual device focus, announcements and font scaling; this target does not claim UI acceptance.
